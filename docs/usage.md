# Usage

```python
import statistics_differ
```

Each module is self-contained; see docstrings for the API:

- `statistics_differ.core` — Core diff engine logic
- `statistics_differ.distribution` — Distribution fitting and hypothesis testing functions
- `statistics_differ.stats_util` — Utility functions for statistical calculations
- `statistics_differ.diff_engine` — Main entry point for the statistics diff engine
- `statistics_differ.merge_tool` — Three-way merge logic for merged results
- `statistics_differ.tests` — Unit tests and test fixtures for the entire module
